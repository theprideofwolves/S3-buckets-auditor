# S3 Auditor interview walkthrough

The maintained source-backed walkthrough is [interviewprep.md](interviewprep.md).
Read [architecture.md](architecture.md) and the
[decision notes](explaining-each-decision-taken-over-others.md) for source paths,
assessment scope and tradeoffs. The CLI's offline reporting fixture remains
available through `go run . -demo testdata/demo.json`.

Start with the four-stage offline [verification example](docs/VERIFICATION.md).
The interview guide covers a three-minute demonstration, the replay state model,
legacy-data handling, partial successes, complexity and honest résumé wording.
